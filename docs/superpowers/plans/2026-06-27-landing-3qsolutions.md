# Landing 3Q Solutions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone marketing landing page for 3Q Solutions (the company selling the 3Q Nexus ERP SaaS) in a new `web-3qsolutions/` Vite project, per the approved spec at `docs/superpowers/specs/2026-06-27-landing-3qsolutions-design.md`.

**Architecture:** A single-page React app (no routing, no backend) assembled from 7 section components (`Navbar`, `Hero`, `Features`, `AgentesIA`, `Planes`, `CtaFinal`, `Footer`) rendered from `App.tsx`. Visual identity (robot-with-circuit-brain hero image, 3 robot-queen mascots for the AI agents) is generated once via the `banana` Claude Code skill (Google Gemini image generation) and committed as static PNG assets — no third-party video/image hotlinking, no runtime image generation.

**Tech Stack:** Vite + React 19 + TypeScript, Tailwind CSS v3, `motion` (the `motion/react` package), Google Fonts (Inter + Outfit).

## Global Constraints

- Project lives in `web-3qsolutions/` at the repo root, fully independent from `frontend/` (the real SaaS app) and `presentacion/` (old static deck). Do not modify those.
- Colors: `--color-brand-green: #9fff00`, `--color-bg-base: #EDEEF5`, primary text `#1a1a1a`, secondary text `#8e8e8e`.
- Fonts: `--font-sans` = Inter, `--font-display` = Outfit, loaded from Google Fonts.
- `body` must carry `@apply bg-bg-base text-zinc-900 font-sans antialiased;`.
- No backend integration, no functional forms — every CTA button/link is a visual placeholder (`href="#"` or a no-op `<button>`), not wired to any API.
- No real contact info yet (phone/email/social) — footer must say so explicitly.
- No third-party video/image hotlinking. All hero/mascot visuals are generated once via the `banana` skill and saved as static files under `web-3qsolutions/src/assets/`.
- The Google AI Studio API key used for image generation lives in `C:\Users\YHONDER\.banana\.env` (`GOOGLE_AI_API_KEY=...`) — it must never be committed to git or written into any file inside the repo.
- This project has no test framework (matches the existing `frontend/` convention, which also has none). "Tests" in this plan means: `npm run build` (runs `tsc -b && vite build`) passing with zero TypeScript errors, plus a manual visual check via `npm run dev`.
- Pricing shown (Básico $29/mes, Pro $79/mes, Max $149/mes) are example placeholders, not final pricing.
