# 3Q Solutions — Landing Page

Sitio de marketing para 3Q Solutions (3Q Nexus: CRM + ERP + agentes de IA).

Proyecto Vite + React + TypeScript + Tailwind CSS + `motion`, independiente de
`frontend/` (la app real del SaaS) y `presentacion/` (deck viejo).

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Sin backend, sin formularios funcionales: todo CTA es un placeholder visual.
Los datos de contacto reales (teléfono, correo, redes) se completan en una
iteración futura.
